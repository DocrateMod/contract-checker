# Проверка договоров — Android

Веб-приложение в `www/index.html`, обёрнутое в Capacitor (`ru.contractchecker.app`).
Данные договоров нигде не хранятся, на сервер ничего не отправляется; в localStorage лежит только дневной счётчик.

## Вариант 1. Без установки чего-либо — через GitHub
1. Создайте приватный репозиторий на github.com и загрузите в него содержимое этой папки.
2. Вкладка Actions → «Build APK» → Run workflow (запускается и сам при загрузке).
3. Когда сборка позеленеет, откройте её и скачайте архив из Artifacts — внутри `Проверка-договоров.apk`.

## Вариант 2. Локально
Нужны Node 20+, JDK 21 и Android SDK (ANDROID_HOME).
```
npm install
npm run build:apk
```
Результат: `dist/Проверка-договоров.apk`.

## Установка на телефон
Перенесите APK на телефон, откройте его и разрешите установку из этого источника. Apk — debug-сборка, для личного использования этого достаточно.
